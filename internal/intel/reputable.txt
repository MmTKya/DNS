# A popularity list is a moving target that would silently change what this
# node will and will not act on between two builds, and the whole value of
# this file is that it does not move.
#

# the internet being broken. What does not: a name that merely happens to be
# busy. Being on this list does not mean a name is safe — it means a single
# threat report is not enough to take it away from everyone.
